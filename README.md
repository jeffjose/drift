# Drift

**Glide for Linux: an open-source Screen Studio, built in Rust.**

Drift is a Linux (X11) port of
[Glide](https://github.com/michaelshimeles/glide) by Michael Shimeles, a fast
native screen recorder for polished product videos. Record your screen, a
window or an area; it re-renders the cursor, zooms into what you click with
spring animations, adds a background, shadow and rounded corners, and exports
MP4 or GIF.

The engine, renderer and editor are Glide's, unchanged, so a frame looks the
same as it does on macOS. Capture, encoding and the desktop integration are
written for Linux, and the macOS code is gone. The app, its binary and its
`.glide` projects keep the Glide name, and this repository keeps Glide's
history so its changes can be merged (see [Following Glide](#following-glide)).

Glide's behaviour was reverse engineered from Screen Studio using REA and
Claude Code (see `analysis/SCREEN_STUDIO.md`). Neither project is affiliated
with or endorsed by Screen Studio or its authors, and neither contains its
code or assets: wallpapers, cursors, device frames, click sounds and the app
icon are generated by Glide's own code.

## Features

- **Recording**: display, window (picked on screen; follows the window) or
  drag-selected area; system audio and microphone on separate tracks;
  countdown, pause/resume, restart and cancel; resize the window you record
  to a preset or custom size; configurable global shortcuts (default
  Ctrl+Alt+Shift+R).
- **Automatic zoom** from clicks with cluster targeting and edge snapping,
  spring physics and motion blur; manual and follow-mouse zooms.
- **Cursor** re-rendered at high resolution with smoothing, tilt, press
  feedback, idle hiding, click circles/ripples and optional click sounds.
- **Styling**: generated wallpapers, gradients, colours, your own image or
  current desktop picture, background blur; padding, roundness, shadow,
  inset, crop, aspect ratios; laptop/phone/tablet device frames; style
  presets. Every change shows on the canvas immediately and in the export.
- **One window**: recording setup in the editor's own layout (a live preview
  of the selected display, window or area under a big Record button); a
  recording opens straight into the editor when you stop; recent recordings
  are a popover off the window title.
- **Editor**: live GPU preview, timeline with clips, zooms and masks; split,
  trim, speed, typing speed-up; blur/pixelate/highlight masks with "data may
  be visible" warnings when the covered content moves; keyboard-shortcut
  overlay; on-device captions with Whisper, editable; voice-over with
  ducking; background music; style presets; undo/redo.
- **Export**: MP4 (H.264/HEVC through the GPU's encoder, NVENC, or
  x264/x265), GIF with delta frames; 720p to 4K, 10–60 fps; quality presets
  with size estimates or "fit to file size"; "Export & copy" to the
  clipboard.

## Build

Needs X11 (not Wayland), a Vulkan GPU, Rust (2024 edition), CMake (for
whisper.cpp) and ffmpeg's libraries. On Debian or Ubuntu:

```sh
sudo apt install cmake libavcodec-dev libavformat-dev libavutil-dev \
  libswscale-dev libswresample-dev libasound2-dev
cargo build --release
target/release/glide
```

Recording uses NVENC when there is one and x264 otherwise
(`GLIDE_ENCODER=software` forces the latter); system audio and the
microphone come from PulseAudio, or PipeWire speaking its protocol. Settings
are in `~/.config/glide` and recordings in `~/Videos/Glide`.

## Different from Glide on macOS

- X11 can't leave a window out of what it reads from the screen. The
  recording controls are only shown where they won't be recorded (beside an
  area or window, or on another display); recording a whole display is
  stopped with the shortcut. The setup preview shows Glide's own window.
- A window recording is the part of the screen the window is on, so
  anything over it is recorded too.
- Without a compositing manager the area and window pickers show a picture
  of the screen taken as they open.
- Shortcuts are stored as Glide stores them: ⌘ is Ctrl, ⌥ is Alt and ⌃ is
  Super.
- Export copies frames through memory and converts them on one CPU thread,
  so it is a good deal slower than Glide's.

Not here yet: a tray icon and cameras. Not coming: iPhone and iPad
recording, Apple Speech captions, voice isolation, hiding the Dock and
desktop icons. `PERFORMANCE.md` and `PROGRESS.md` are Glide's and describe
macOS.

## Command line

```sh
glide                               # open the app
glide record -t 10                  # record the main display for 10 s
glide record --area 200,150,1280,720 --mic
glide export ~/Videos/Glide/Recording.glide --height 1080
glide export Project.glide --format gif
glide devices                       # displays, windows, microphones
glide check-masks Project.glide     # where content under masks moves
glide check-background Project.glide # every background option visibly changes a frame
glide audio-check Project.glide --freq 880 # levels, and how much is a test tone
glide transcribe Project.glide --engine whisper-small  # captions
glide resize-window 1234 1920x1080  # window id from `glide devices`
glide synth demo.glide              # synthetic project (needs no screen)
cargo test                          # unit, round-trip and UI smoke tests
```

## Layout

- `src/engine` — pure, tested model of every frame: springs, deterministic
  animator, time mapping, sizes, zoom, cursor, camera, captions, masks,
  device frames, typing detection.
- `src/render` — wgpu (Vulkan) compositor: one uber-shader with modes for
  backgrounds, shadows, the rounded window, blur, masks and device frames.
- `src/capture`, `src/recorder` — X11 screen capture over shared memory,
  PulseAudio, and input logging (XInput2, XFixes) into a `.glide` package.
- `src/media`, `src/export` — libav decode and encode, audio mix, GIF.
- `src/app` — the egui app (Inter font): one editor-first window, the
  recording controls, the area and window pickers, global shortcuts.

## Following Glide

`upstream` is Glide; `main` is Drift, a few commits on top of it.

```sh
git remote add upstream https://github.com/michaelshimeles/glide   # once
git fetch upstream
git merge upstream/main
```

Changes to the engine, renderer and editor merge as they are. Where Glide
changes a file that is macOS code there (`src/capture`, `src/media`,
`src/recorder`, and `hotkey`, `menubar`, `recbar` and `voiceover` in
`src/app`), git reports a conflict with the Linux file of the same name:
keep the Linux one, and port what the change does if it matters here.
